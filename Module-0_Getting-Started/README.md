# Module 0 – Getting Started

## Overview

This module covers the setup needed for the rest of the workshop: a Linux environment and the open-source VLSI tools.

## Topics Covered

### 1. Lab Setup

- Cloud lab and local lab options
- Linux (Ubuntu) command line basics
- Working with files, folders and a text editor

### 2. Tools Installed

- Icarus Verilog for simulation
- GTKWave for waveforms
- Yosys for synthesis
- SKY130 liberty (.lib) cell library

### 3. Basic Flow

- Write Verilog and a testbench
- Compile and run with iverilog and vvp
- Open the VCD file in GTKWave
